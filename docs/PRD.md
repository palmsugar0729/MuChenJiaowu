# PRD：沐晨课程管理系统

## 产品概述

培训机构（沐晨）的课程管理系统。由桌面版「工资结算表生成器」升级而来 ——
桌面版原本供教师录入上课记录、自动计算薪酬并导出 Excel，现逐步退役
（只保留算课时 + 导考勤表），主线迁往网页版 + 微信小程序。

## 目标用户

- **当前**：机构内部使用（超管 / 管理员 / 老师三种角色）
- **远期**：老师用手机看课表、签到；管理员在后台管班级、学生、课时和考勤

## 核心功能

### 1. 上课记录录入
- 输入/选择：教师姓名、日期、开始时间、课时数（浮点数）、班级名（必填，可编辑下拉）、班级类型（下拉菜单）、备注
- 点击"添加"存入当前列表

### 2. 预览列表
- 表格形式展示所有已录入记录（含班级名列）
- 自动显示：星期、时薪（按班级类型）、薪酬（课时数 × 时薪）
- 支持日期筛选：显示全部 / 仅显示某一个月
- 支持删除记录

### 3. Excel 导出
- 用户选择保存路径和文件名
- 生成格式参考 `screenshot_original-effect.png` 及参考 Excel 文件
- 按班级名自动着色区分（同班级名同色）
- 导出范围跟随当前日期筛选（全部 / 某月）

**已定死的业务规则**（详见 [AGENTS.md](AGENTS.md) 后端规则一节）：

- **课时余额不存字段**，一律由流水求和算出 —— 涉及钱，必须可追溯
- **谁被扣课时看班型，不看单个学生的出勤**：**1对1 / 1对2 只有「出勤」才扣**
  （课时是学生自己买的，上几次扣几次，人没来这节课就没上，收钱没道理）；
  **其他班型开课就扣全员**，请假缺勤照样扣（小班的课时是整班一起走的，
  请假也占着时段和老师）。只有取消课程不扣 — 1对2 于 **2026-10-07** 归入第一档
- **课时不够就整节课失败**：400 并列出是谁、还剩多少、需要多少，**绝不扣成负数**
  （「余额可以为负」只留给手工 `adjust` 纠错/退费）
- **考勤一改，课时跟着重算**：事后把 1对1 / 1对2 的出勤改成请假，那节课的课时会退回去
- **只有学生一本课时账**：`hour_transactions` 每行都挂 `student_id`；班级那边的
  `total_hours` 是 `SUM(lessons.hours)` 现算的**只读展示值**，不参与任何扣减
  — 2026-10-07 确认口径
- **费率必须快照**：排课时抄一份班级费率进 `lessons.rate`，绝不实时 JOIN ——
  改一次费率会篡改历史工资表
- **三种「课时」不能混**：教师课时费 / 班级已上课时 / 学生独立余额
- **扣课时只有一个入口**：「完成上课」事务。手工流水只允许充值 / 调整，录入「消耗」一律拒绝
- **老师只能操作自己的课**：排课限管理员；完成 / 考勤 / 查看都限 `lesson.teacher_id == 自己`
- **班级是在册人数有上限的**：1对1 限 1 人、1对2 限 2 人、**小班（1对3/1对4/1对5）统一限 5 人**
  —— 小班三档**共用 5 人上限**，不是「1对3 只能坐 3 个」。认不出的自定义类型不限制
- **班级和学生的删除语义不一样**：班级真删（有课程记录时禁止，只能停用），学生软删
