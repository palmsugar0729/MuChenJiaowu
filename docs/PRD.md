# PRD：工资结算表生成器

## 产品概述

一款 Windows 桌面应用，供教师录入上课记录，自动计算薪酬并导出为工资结算表 Excel 文件。

## 目标用户

- **当前**：个人使用（每月底集中录入并导出）
- **中期**：公司同事（不同使用习惯，可能需要逐日录入）
- **远期**：升级为**课程管理系统**（网页 + 微信小程序），桌面版只保留算课时 + 导考勤表

## 核心功能

### 1. 上课记录录入
- 输入/选择：教师姓名、日期、开始时间、课时数（浮点数）、班级名（必填，可编辑下拉）、班级类型（下拉菜单）、备注
- 点击"添加"存入当前列表

### 2. 预览列表
- 表格形式展示所有已录入记录（含班级名列）
- 自动显示：星期、时薪（按班级类型）、薪酬（课时数 × 时薪）
- 支持日期筛选：显示全部 / 仅显示某一个月
- 支持删除记录

### 3. Excel 导出
- 用户选择保存路径和文件名
- 生成格式参考 `screenshot_original-effect.png` 及参考 Excel 文件
- 按班级名自动着色区分（同班级名同色）
- 导出范围跟随当前日期筛选（全部 / 某月）

## 技术方案

| 模块 | 技术 | 说明 |
|---|---|---|
| GUI | PySide6 | LGPL 协议，组件丰富 |
| Excel | openpyxl | Python Excel 读写标准库 |
| 存储 | JSON | 本地文件，轻量零依赖 |
| 语言 | Python 3.10+ | |

## 数据模型

```python
Record(date, start_time, hours, class_type, class_name, note)
MonthData(teacher_name, records: list[Record])
```

## 班级费率配置

| 班级类型 | 时薪（元/时） | 状态 |
|---|---|---|
| 1对1 | 80 | 在用 |
| 1对2 | 100 | 在用 |
| 1对3 | 100 | 在用 |
| 1对4 | 110 | 在用 |
| 1对5 | 120 | 在用 |

费率配置放在独立模块中，支持手动新增/修改。

## Excel 导出规范

详见 [docs/2026-05-31-需求讨论记录.md](docs/2026-05-31-需求讨论记录.md#excel-格式规范基于参考文件解析)

简要：
- A~J 列，共 10 列，第1行标题行（合并单元格）
- 第2行显示教师姓名
- 第3行表头
- 第4行起数据
- 末行合计
- 薪酬列使用 Excel 公式而非硬编码数值
- 按班级名同背景色（同班级名同色）
- 导出范围跟随日期筛选

## 非功能需求

- 架构分层：数据模型 → 存储层 → UI 层，模型层不引用框架代码
- 为未来迁移 uniapp 留余地
- 不引入数据库，不引入不必要的抽象

**已定死的业务规则**（详见 [AGENTS.md](AGENTS.md) 后端规则一节）：

- **课时余额不存字段**，一律由流水求和算出 —— 涉及钱，必须可追溯
- **出勤状态不影响扣课时**：出勤 / 请假 / 缺勤**都扣**，只有课程取消不扣
- **费率必须快照**：排课时抄一份班级费率进 `lessons.rate`，绝不实时 JOIN ——
  改一次费率会篡改历史工资表
- **三种「课时」不能混**：教师课时费 / 班级已上课时 / 学生独立余额
- **班级和学生的删除语义不一样**：班级真删（有课程记录时禁止，只能停用），学生软删
