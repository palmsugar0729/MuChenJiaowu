## 四、逐条讨论与结论

### 决策 1：FastAPI vs Django → ✅ **FastAPI**

**Claude 先澄清了一个关键误解**：

> 「**以后学生/老师变多，要不要换框架**——这个担心不成立。FastAPI 和 Django 处理几千上万用户都没问题，**框架不是瓶颈**。真正决定能扛多少人的是**数据库**（SQLite → PostgreSQL），跟框架无关。」

**逐条回应用户的三个顾虑**：

| 顾虑 | 回应 |
|---|---|
| 自己写管理界面代价大吗？ | **中等，但比看起来小**。你本来就要求老师能看学生和班级（只读），这些页面**无论如何都要用 uniapp 写一遍**；管理员无非在同一套页面上多几个增删改按钮，边际成本很小 |
| Django 后期维护麻烦吗？ | **会更麻烦**，因为会得到**两套前端、两套登录、两套权限**。Django 后台风格老旧、手机难用，只适合电脑上录数据 |
| FastAPI 转 Django 麻烦吗？ | **很麻烦，等于重写**。但你不会因为「人多」需要转 |

**用户最终决定**：

> 「既然 Django 会导致两套系统运维麻烦，那还是 FastAPI 吧。毕竟和人数多少没关系。」

**→ 结论：FastAPI** ✅

### 决策 5：服务器与域名 → ✅ ~~**用现有的，不必再租**~~

> ⚠️ **本节结论已于 2026-09-26 推翻**（因系统将被公司买断，改为独立新服务器）。以下保留当日讨论原貌，**不要照此执行**，以 `docs/后端方案设计.md` 第十节为准。

**Claude 的结论**：

| 考虑 | 结论 |
|---|---|
| 负载 | 两个低流量项目（刷题背单词站 + 本系统）+ 几个老师，**绰绰有余** |
| 资源占用 | FastAPI + SQLite 内存占用极小（几十 MB 量级） |
| 是否再租 | **不必**。35/月 那台 2核2G 也够，但没必要——多花钱、多一台要维护 |
| 何时该升级 | 内存/CPU 长期吃紧、带宽跑满，或想隔离故障风险时 |

**域名方案**：一个一级域名可挂**无限子域名**，全部指向同一台服务器，Nginx 按子域名分流：

```
palmsugar.cn                 ← 已备案的一级域名
├── www.palmsugar.cn         ← 主站
├── jiaowu.palmsugar.cn      ← 本系统（课程管理系统）
└── quiz.palmsugar.cn        ← 现有的刷题背单词站
```

**⚠️ 提醒的坑**：ICP 备案绑定「**域名 + 接入商**」，**换服务器或新增服务器需要做「备案接入」变更**，否则域名可能被断。

**→ 结论：用现有 4核4G40G，不必再租；一级域名挂子域名** ✅

## 五、⭐ 本轮最重要的澄清：三种「课时」

**用户在讨论中提出了一个关键的业务规则**，Claude 据此提炼出「三种课时」的概念区分：

### 用户原话

> 「我的意思是，我们这边上课主要是根据班级来的，就算一个学生请假，也算课时的。除非这次课不上。所以一般来说，一次课上好，课程的课时扣，学生的课时也同步扣。但是有时候，有些学生只买几节课，或者同时参加2个班级，这样的话，他们的课时总数有可能和一个班级的不一样对不对？所以每个学生信息都需要一个单独的课时数扣，不然肯定对不上。」

### 提炼的模型

系统里有**三种完全不同的「课时」**，混在一起就会对不上账：

| # | 概念 | 归属对象 | 计算方式 | 用途 |
|---|---|---|---|---|
| **1** | **教师课时费** | **老师** | 上了多少节课 × 时薪 | 算工资、导考勤表（= 现有桌面版那套） |
| **2** | **班级已上课时** | **班级** | 这个班累计上过多少次课 | 班级管理页展示 |
| **3** | **学生所剩课时** | **每个学生各算各的** | 购买 − 消耗（流水求和） | 学生管理页展示、家长查询 |

### 为什么学生课时必须独立于班级

因为实际情况是：
- 有学生**只买几节课**（不跟班级的完整课时包走）
- 有学生**同时参加两个班级**

所以**学生的课时余额和班级的课时数天生就不一样**。如果把余额挂在班级上，**一定对不上**。

### 扣课时的规则（已确认）

```
一次课正常上了（这节 hours = 2.5）
   → 班级的「已上课时」+2.5
   → 老师的「课时费」+2.5 小时 × 时薪
   → 该班每个学生的「所剩课时」各扣 2.5   ← 每人扣自己的
```

> **📌 2026-09-18 补注**：上面原文的「各扣 1 次」措辞有歧义，已确认澄清——**「课时」就是「小时数」**，扣的是这节课的 `hours`，不是固定扣 1。用户原话：「课时就是小时数哦……我们直接按多少小时算。比如一个班级 48 小时，第一天上 2.5h 第二天上 3h，那就扣 5.5h。」

| 情况 | 扣不扣课时 | 说明 |
|---|---|---|
| 正常上课 | ✅ 扣 | 全班学生都扣 |
| 学生**请假** | ✅ **照样扣** | 用户明确：「就算一个学生请假，也算课时」 |
| 学生缺勤/旷课 | ✅ 照样扣 | 2026-09-18 已确认，同请假逻辑 |
| **课程取消**（这次课不上） | ❌ **不扣** | 唯一的例外 |

> **重要推论**：出勤状态（出勤 / 请假 / 缺勤）**不影响扣课时**，它只是**记录**（谁来了谁没来）。
> 真正决定扣不扣的是**课程本身有没有上**（`lessons.status`）。

### 实现方式

学生**不存**冗余的 `remaining_hours` 字段，而是用 `hour_transactions` 流水表记账（购买 / 消耗 / 调整），**余额 = 流水求和**。因为涉及钱，家长问起来必须能查出每一笔的来源。

## 六、小程序相关问题

### 一个微信账号能挂多少个小程序？

| 主体类型 | 可注册数量 |
|---|---|
| **个人** | **5 个** |
| 个体工商户 | 5 个 |
| **企业 / 政府 / 媒体 / 其他组织** | **50 个** |

补充：**一个邮箱只能注册 1 个小程序**；一个手机号最多绑定 5 个；同一主体下的所有小程序（含已注销、封禁的）都计入上限。

### 小程序的硬性门槛

1. **必须 ICP 备案**——且**备案主体要与小程序认证主体一致**（个人备案不能用于企业类小程序）。流程：提交 → 平台初审（1~2 工作日）→ 工信部短信核验 → 通管局审核（**1~20 个工作日**）
2. **必须 HTTPS**——HTTP 被全面禁用；证书要有效、TLS 1.2+、域名与后台登记完全一致
3. **域名要在微信后台配置**（`request` 合法域名等），还要放校验文件到网站根目录

> ⚠️ **个人主体不能使用 `web-view`**。不过 uniapp 是**编译成原生小程序代码**，不是 web-view 套壳，所以不受影响。

### 用户的思路：先网页、后小程序 → ✅ **完全正确**

理由：
1. 网页版能**快速验证功能**，改一版几分钟，不用等审核
2. **uniapp 同一套代码**，后面编译成小程序，**前端代码基本复用**
3. **小程序有备案 + 审核周期**，放后面不会卡住前面进度
4. 前一个项目小程序也没做——**先跑通一个，再复制经验**

**唯一要提前准备的**：如果最终要上小程序，**备案主体最好和小程序主体一致**，别到时候才发现对不上。

## 十、给后续开发的注意事项

### 硬性约束

| 约束 | 说明 |
|---|---|
| **保留桌面版 exe** | 必须保留到网页版和小程序上线为止。用户每月靠它给领导交报表 |
| **不要删历史 exe** | `codes/dist/` 下的历史版本，打包时用不同 `--name` 共存 |
| **文档要同步** | PRD / 开发日志 / 本系列讨论记录，改完代码要同步更新 |

### 环境相关

| 事项 | 说明 |
|---|---|
| **git push 需要开 VPN** | git 配了本地代理 `127.0.0.1:7897`（Clash Verge）。VPN 关着时 push 必定失败（`Failed to connect ... via 127.0.0.1`）；开着偶尔也会断（`Recv failure: Connection was aborted`），**重试即可**，不要改代理配置 |
| **项目已移动到 `D:\WorkSpace\projects\mix`** | 移动后 Claude Code 的**项目记忆目录名会随路径变化**，新路径下是全新的记忆空间 |
| **品牌主色** | `#a9c5b3`，所有 palmsugar 项目通用 |

### 别踩的坑

| 坑 | 说明 |
|---|---|
| **三种课时混淆** | 教师课时费 / 班级已上课时 / 学生独立余额，**三个完全不同的概念**，别混 |
| **学生余额挂班级** | 一定对不上——有学生只买几节课、有学生上两个班 |
| **用出勤状态决定扣课时** | 错。请假也扣，出勤状态只是记录 |
| **备案接入变更** | 换服务器要办，否则域名可能被断 |
| **Excel 班级配色 ≠ 品牌色** | 前者目标是「色差大易区分」，与品牌色无关 |
